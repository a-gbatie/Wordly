# Wordly
# Dictionary Single Page Application

A single-page dictionary application built with HTML, CSS, and JavaScript. Users can search for a word and retrieve dictionary information from an external API.

## Features

- Search for a word
- Display definitions
- Display synonyms when available
- Display pronunciation information
- Play pronunciation audio when available
- Handle invalid or empty searches
- Update the page dynamically without reloading

## Technologies

- HTML
- CSS
- JavaScript
- Fetch API
- Free Dictionary API

## Purpose

This project demonstrates building a Single Page Application (SPA) using event listeners, asynchronous API requests, DOM manipulation, and dynamic content rendering." > README.md
